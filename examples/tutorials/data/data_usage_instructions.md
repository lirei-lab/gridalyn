# Tutorial Data Usage Instructions

`examples/tutorials/data/` contains small tutorial and regression datasets used
by example scripts and tests. Real case-study or tutorial GeoJSON files should
live here, not inside the importable `gridalyn` package.

Use the compatibility helper when existing code needs a path:

```python

path = get_dataset_path("buildings_inside_polygon.geojson")
```

The helper resolves files from this directory first. `gridalyn/data` is reserved
for lightweight discovery code and temporary backward-compatible package data.

## PyCity Simulation Data

This document provides instructions on how to access and interpret the simulation data generated by `pycity_base/examples/example_district_generator_parallel.py`. The data is stored in an HDF5 file named `simulation_results.h5`.

## File Location

The `simulation_results.h5` file is located in `examples/tutorials/data/`.

## Data Structure

The HDF5 file contains two main datasets (keys):

1.  **`/power_consumption`**: Aggregated total power consumption for each simulated building.
2.  **`/weather_data`**: Environmental weather data used during the simulation.

Both datasets are stored as Pandas DataFrames.

### `/power_consumption` Data Structure

This DataFrame contains the total aggregated power consumption for each building over the simulation period.

*   **Index**: Time steps of the simulation (DatetimeIndex).
*   **Columns**: Each column represents a building's total power consumption.
    *   **Naming Convention**: `Building_X_TotalPower_W`, where `X` is the node ID of the building in the city district.
    *   **Units**: Watts (W). This is the sum of space heating, space cooling, electrical, and domestic hot water power.

### `/weather_data` Data Structure

This DataFrame contains various weather parameters for the simulation period.

*   **Index**: Time steps of the simulation (DatetimeIndex).
*   **Columns**:
    *   `t_ambient_C`: Ambient temperature in degrees Celsius (°C).
    *   `q_direct_W_per_m2`: Direct normal irradiance in Watts per square meter (W/m²).
    *   `q_diffuse_W_per_m2`: Diffuse horizontal irradiance in Watts per square meter (W/m²).
    *   `v_wind_m_per_s`: Wind speed in meters per second (m/s).
    *   `phi_ambient_percent`: Relative humidity in percent (%).
    *   `p_ambient_Pa`: Ambient pressure in Pascals (Pa).
    *   `cloudiness_percent`: Cloudiness in percent (%).

## How to Load and Use the Data (Python Example)

You can load these datasets into Pandas DataFrames using the `pandas.read_hdf` function.

```python
import pandas as pd
import os

# Define the path to the HDF5 file
output_dir = 'pycity_base/examples/output_data'
hdf5_filepath = os.path.join(output_dir, 'simulation_results.h5')

try:
    # Load aggregated power consumption data
    df_power_consumption = pd.read_hdf(hdf5_filepath, key='power_consumption')
    print("Successfully loaded aggregated power consumption data:")
    print(df_power_consumption.head())
    print("\nDataFrame Info:")
    df_power_consumption.info()

    print("\n" + "="*50 + "\n")

    # Load weather data
    df_weather = pd.read_hdf(hdf5_filepath, key='weather_data')
    print("Successfully loaded weather data:")
    print(df_weather.head())
    print("\nDataFrame Info:")
    df_weather.info()

except FileNotFoundError:
    print(f"Error: The file '{hdf5_filepath}' was not found. "
          "Please ensure you have run example_district_generator_parallel.py first.")
except KeyError as e:
    print(f"Error: Missing HDF5 key. {e}. "
          "Ensure the keys 'power_consumption' and 'weather_data' exist in the file.")
except Exception as e:
    print(f"An unexpected error occurred: {e}")

# Example: Accessing data for a specific building
# Replace 'Building_X_TotalPower_W' with an actual column name from your data
if 'df_power_consumption' in locals() and not df_power_consumption.empty:
    first_building_column = df_power_consumption.columns[0]
    print(f"\nFirst building's total power consumption (first 5 values):")
    print(df_power_consumption[first_building_column].head())

# Example: Accessing ambient temperature data
if 'df_weather' in locals() and not df_weather.empty:
    print(f"\nAmbient temperature (first 5 values):")
    print(df_weather['t_ambient_C'].head())
