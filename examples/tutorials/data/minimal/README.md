# Minimal Tutorial Dataset

This directory is the only approved demo-data area tracked in Git. It is for
quickstart and smoke-test examples that should run without downloading external
artifacts.

Rules:

- keep the whole directory under 10 MB;
- prefer GeoJSON, JSON, YAML, and tiny CSV files;
- avoid full digital-twin Parquet outputs;
- do not store project outputs, simulation caches, or manuscript figures here;
- document every file and how it is regenerated.

Full study artifacts belong outside Git and should be regenerated by workflows
or fetched from an external artifact store.

## Files

- `manifest.json`: dataset metadata and the file inventory.
- `grid_nodes.geojson`: three connectivity nodes for a tiny radial feeder.
- `grid_edges.geojson`: two feeder segments with simple ratings.
- `buildings.geojson`: three buildings linked to LV buses with small EV/CLS
  attributes.
- `scenarios.json`: a baseline and a compact EV flexibility scenario.
- `expected_summary.json`: deterministic counts and totals for smoke tests.

The files are intentionally tiny. They are not a replacement for the
Trois-Rivieres study data; they are a stable quickstart fixture.
