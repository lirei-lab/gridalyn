# Tutorials

Tutorials are task-oriented. They show how to produce or inspect artifacts using
the current command-line interface and project layout.

Start with:

1. [Build A Minimal Digital Twin](build-minimal-digital-twin.md)
2. [Create Synthetic Networks From GeoJSON](synthetic-network-from-geojson.md)
3. [Run Flexibility CLS](../workflows/flexibility-cls.md)
4. [Generate Reports And Figures](generate-reports-and-figures.md)
5. [Open The Dashboard](open-dashboard.md)
6. [Create A New Project](../workflows/creating-new-workflow.md)

The tutorials intentionally call reusable platform commands. If a task requires
copying a large project script, that behavior should probably move into
`gridalyn/` first.
